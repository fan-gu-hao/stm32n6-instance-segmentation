## 長時間觀察的限制

觀察約 1800.1 秒，取得 18054 個完整影格封包。
開頭出現影格 334 → 5464 的序號不連續，以及一列截斷的效能紀錄。
後續可核對的連續板端週期合計 1791.297 秒，即 29 分 51.297 秒。

原始基本檢查結果保留，不能寫成「30 分鐘零異常通過」。
接收端既有資料銜接是待確認的可能原因，尚未證實根因。
這項序號異常不能直接當作攝影機感測器丟幀。

使用者在長時間觀察期間刻意走進走出。
69 次進入與 68 次離開事件沒有逐次人工對照，因此不據此計算漏報率。

## 故障測試範圍

測試副本完成影格 0～49 後，刻意忽略擷取完成通知，
觸發原有逾時處理，回報 INVALID 與 CAPTURE_TIMEOUT。
故障後再觀察至少 10 秒，沒有繼續發布偵測結果。
螢幕失效提示與舊框清除由使用者確認。

此項為軟體故障注入，不代表已測試實體攝影機斷線或全部錯誤分支。
測試後已恢復正式 A1 韌體；故障測試映像不是交付版本。
A4 的 B 記憶體配置保留為實驗結果，正式攝影機版本沿用 A1。
