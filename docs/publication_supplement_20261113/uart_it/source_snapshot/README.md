# 串列中斷試驗的可閱讀來源快照

這些原檔取自本機安裝／還原前的備份。內容逐位元組保存，來源與 SHA-256 見 [provenance.json](provenance.json)；已有[修補與部署／還原證據](../)共同說明實驗的完整過程。

| 程式 | 實作與版本 |
| --- | --- |
| [project_uart_it.c](Src/project_uart_it.c) | 4096 位元組環形佇列、完整列發布、重要訊息預留、HAL 中斷傳輸、短臨界區、記憶體屏障、回呼釋放空間與錯誤／高水位統計 |
| [project_uart_it.h](Inc/project_uart_it.h) | 佇列容量、512 位元組逐列緩衝、256 位元組重要訊息預留與統計介面 |
| [main.c](Src/main.c) | 當時的應用整合快照；此檔屬於試驗分支，不替換現行 firmware/ 的正式主程式 |
| [初版安裝工具](install_uart_it_v1_initial.py) | 來源結構檢查、修改前指紋、備份、原子更新、修改驗證、建置與佇列模擬檢查入口 |
| [HAL 相依修正版](install_uart_it_v1_hal_fix1.py) | 補入 IDE 的官方 HAL IRQ 相依，並以 ELF 符號／區段核對中斷與回呼及佇列配置 |

傳送採 `HAL_UART_Transmit_IT`，不是 DMA。主迴圈先複製完整一列，再以短臨界區發布佇列頭；完成回呼釋放已傳送的空間。容量不足、過長列、中斷內呼叫及 HAL 錯誤皆有明確處理與統計。

[建置紀錄](../build_20260914_055733_234190.json)記錄強符號回呼與 HAL 相依檢查；[部署紀錄](../deploy_20260914_060547_683657/manifest.json)記錄應用寫入驗證；[還原紀錄](../rollback_20260914_061621_901943/manifest.json)記錄來源及原應用映像恢復。部署與還原紀錄的 `hardware_runtime_verified` 均為 false，沒有獨立效能比較可據以宣稱加速，還原原因也不由檔名推定。

工具保留原開發路徑與可修改／建置的選項，供審閱歷史工程實作；本次封存沒有執行這些工具。正式 A1 基準仍以既有原始碼、凍結及驗證紀錄為準。
