## 重建材料與順序
1. 取得上述兩個官方基底版本。
2. 分別套用 model_zoo.patch、n6.patch。
3. 將 new_files/n6/ 下的檔案放回 N6 倉庫對應位置。
4. 依 source_lock.json 的 deleted_paths 移除舊版函式庫。
5. 將 dependencies.json 所列三份二進位檔放回指定位置並核對雜湊。
6. 以 STM32CubeIDE 的 ModelZoo 組態乾淨重建。
